GitHub'ga ulanish

Panel kinolarni to'g'ridan-to'g'ri saytingizga yozishi uchun GitHub kaliti (token) kerak. Kalit faqat shu qurilmada saqlanadi.

Token qanday olinadi (2 daqiqa)
  1. github.com'ga kiring → o'ng yuqoridagi rasmingiz → Settings.
  2. Chap menyuning eng pastida Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Token name: ekran-tv-panel. Expiration: 1 yil (yoki o'zingiz tanlang).
  4. Repository access → Only select repositories → ekran-tv ni tanlang.
  5. Permissions → Repository permissions bo'limida: Contents → Read and write, Pages → Read and write.
  6. Pastdagi Generate token ni bosing, chiqqan kalitni nusxalab shu yerga qo'ying.

Yangi kino

Qaysi bulutlar ishlaydi?
  1. YouTube — bepul. Videoni «Ro'yxatda yo'q» (Unlisted) qilib yuklang va havolasini qo'ying.
  2. Bunny Stream (bunny.net) — arzon, reklamasiz, tez. Video → Embed havolasini qo'ying (iframe.mediadelivery.net/embed/...).
  3. Vimeo — video sozlamalarida joylashtirishga ruxsat bering, so'ng video havolasini qo'ying.
  4. Har qanday bulutdagi .mp4 fayl (Cloudflare R2, Backblaze B2, o'z serveringiz) — fayl ommaviy bo'lishi va havola .mp4 bilan tugashi kerak.
  5. Dropbox — sinov uchun yaraydi, lekin ko'p tomoshabin bo'lsa Dropbox havolani bloklaydi.
  6. Google Drive ishlamaydi: u videoni boshqa saytda ko'rsatishga ruxsat bermaydi va ko'p ko'rilganda bloklaydi.
Saqlangach, pastdagi «Saytga chiqarish» tugmasini bosing.
